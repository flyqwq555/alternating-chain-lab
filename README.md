# alternating-chain-lab

[![tests](https://github.com/flyqwq555/alternating-chain-lab/actions/workflows/test.yml/badge.svg)](https://github.com/flyqwq555/alternating-chain-lab/actions/workflows/test.yml)

交替高斯粒子链（Alternating Gaussian Particle Chains）的**全区间相图、多粒子推广与高精度符号/区间算术验证库**。

## 背景与问题

考虑周期区间 $[0, N)$ 上的 $N=2k$ 个交替粒子（$A$ 类在偶数编号位，$B$ 类在奇数编号位），势函数为 $f(r)=e^{-r^2/4}$，周期化高斯核与归一化能量为

$$K_N(x) = \sum_{m\in\mathbb Z} e^{-(x + mN)^2 / 4}, \qquad E_N(x) = 1 - \frac{1}{N}\sum_{i,j=0}^{N-1} (-1)^{i+j} K_N(x_i - x_j).$$

原始猜想（Bétermin–Knüpfer–Nolte, *J. Stat. Phys.* 181 (2020)）认为等距构型是极小元，该猜想已被反例推翻。本库研究的是**附加最小间距约束**后的情形：相邻粒子（含跨周期边界）间距 $\Delta x_i \ge h > 0$ 时，全局极小构型随 $h$ 如何变化。

## 主要结果

### 1. 等距能量的 $N$ 无关恒等式（已验证）

对任意偶数 $N$，等距构型能量由 Poisson 求和可化为与 $N$ 无关的常数：

$$E_{\rm eq} = 1 - 2\sqrt{\pi}\sum_{m\in\mathbb Z} e^{-\pi^2(2m+1)^2} \approx 0.99963329215773 .$$

代码中对 $N=4,6,8,10$ 的数值结果与之一致（见 `tests/test_verification.py`）。

### 2. $N=4$：已证的小间距全局结论与数值相图

| 区间 | 最优候选 | 状态 |
|---|---|---|
| $0 < h \le \frac{1}{2\pi}\approx0.159155$ | $(0,\ 2-h,\ 2,\ 2+h)$，即 `1+3` | **全部合法构型的全局唯一性已证（定理 5）** |
| $\frac{1}{2\pi} < h \le h_{c}\approx 0.668019115487$ | 同上 | $A/B$ 比较已证，全局最优性为数值搜索 |
| $h_{c} < h \le 1$ | $(0,\ h,\ 2h,\ 3h)$，三间隙锁死 | $A/B$ 比较已证，全局最优性为数值搜索 |

- $h_c$ 是两条候选能量曲线的横截交点，$F'(h_c)>0$。在“只有 $A/B$ 两类候选”的范围内，这给出能量导数跳变的一阶相变；全部合法构型的全局相变仍未证明。
- 对称构型在 $h_{\rm instab}\approx 0.668467328360$ 处才失去横截方向稳定性，故 $h_c < h_{\rm instab}$。单个方向的曲率不能排除其他稳定破缺分支。
- $h\to 0^+$ 时能量展开（高精度，35 位有效数字）：

$$E_{\min}(h) = 0.84968709956550819822974764962157635 + 0.37088222385492727532572984863694225\, h^2 - 0.30727100350984768807755528263806634\, h^4 + O(h^6)$$

### 3. $N=6,8,10$：小间距下团簇分裂（数值结果，非证明）

多起点 SLSQP（全构型可行性校验）得到的全局极小能量：

| $h$ | $N=4$ | $N=6$ | $N=8$ | $N=10$ |
|---|---|---|---|---|
| 0.05 | 0.850612386 | 0.738292875 | 0.760722060 | 0.767527493 |
| 0.20 | 0.864037361 | 0.759371386 | 0.782789721 | 0.787607068 |
| 0.50 | 0.924751873 | 0.858959722 | 0.873131477 | 0.876928863 |
| 0.75 | 0.972665746 | 0.954620201 | 0.953235043 | 0.945112339 |
| 1.00 | 0.999633292 | 0.999633292 | 0.999633292 | 0.999633292 |

观察到：小 $h$ 下最优构型**不是**单个 `1+(N-1)` 大团簇，而是分裂成多个紧致团簇（$N=6$: `3+3`；$N=8$: `1+5+2`；$N=10$: 五对 `2+2+2+2+2`）；大 $h$（如 0.75）下则趋向单链加一个大间隙。

> 注意：$N\ge 6$ 的结果是**数值全局搜索**（多起点 + 可行性复核），不构成全局最优性证明。

## 严格证明

[`docs/proof-n4-phase-transition.md`](docs/proof-n4-phase-transition.md) 给出 $N=4$ 相变的严格短证明：

- **定理 1**：两个候选构型 $E_A(h)$、$E_B(h)$ 的精确闭式；
- **定理 2**：$F=E_A-E_B$ 在 $(0,1)$ 内存在唯一零点 $h_c=0.66801911548686144337\ldots$，且 $F'(h_c)>0$（横截相交，即一阶）；
- **定理 3**：$t$ 消元（包络定理）的完整推导，限定在 $1+3$ 拓扑的盒 $\delta\le u,v\le3\delta$、$|t|\le4\delta$ 内。修正后的认证范围是 $\delta\le0.0868$（即 $h\le0.0553$）。该局部结论不再被误写成整个 $1+3$ 拓扑；
- **定理 4**：$h_c<h_{\rm instab}=0.66846732835982469912\ldots$。两条候选能量在交点处相等，下包络连续而左右导数跳变；这证明候选意义下的一阶相变，不证明全部构型的全局分类；
- **定理 5**：$0<h\le1/(2\pi)$ 时，全部合法构型的全局极小构型唯一为 $(0,2-h,2,2+h)$（按平移、反射和循环重标号计）。证明包含谱稳定性、定量聚类、进入大盒以及盒内变分，补上了第 6 节的小间距缺口。

文档中每个数值常数都由 [`scripts/verify_proof.py`](scripts/verify_proof.py) 以 50 位精度计算并认证，级数截断误差由显式几何优级数控制（$<10^{-30}$）：

```bash
python scripts/verify_proof.py
```

第 6 节明确列出**尚未证明**的部分（全部合法构型下的全局最优性），不把数值证据当作证明。

## 工程保证

- **可行性保证**：所有优化器返回值都经 `_is_feasible()` 校验（每段间隙 $\ge h$、间隙和 $= N$），SLSQP 返回的不可行点一律丢弃并用构造性可行构型兜底。
- **独立审计**：`scripts/audit_reference.py` 提供不依赖 numpy 的朴素双循环实现，用于交叉验证 `energy_per_particle`（当前逐点误差 $0$）。
- **严格不等式**：`rigour.py` 用 `mpmath` 55 位精度 + `mpmath.iv` 区间算术验证 $q<1/8$、尾项界与稳定性常数。

## 关于证明细节的一处澄清

小间距局部证明中，$\partial E/\partial u$ 的正性**不能**直接对 $u$ 求偏导得到：原始形式为

$$\frac{\partial E}{\partial u} = -\frac{1}{2}\Big(g''(0)\,v + g''(\pi)\,(t-u)\Big) + O(\delta^3),$$

当 $t$ 未固定时可取负值。正确顺序是先由 $\partial_t E = 0$ 解出 $t^*(u,v) = u - v + O(\delta^3)$，再对 $u,v$ 求**全导数**（包络定理），才得到

$$\frac{dE}{du}\Big|_{t=t^*} = \frac{g''(\pi)-g''(0)}{2}\,v + O(\delta^3) > 0 .$$
